# Lessons

What went wrong while building Market Desk, why, the fix, and the rule for next time.
Newest at the bottom. Add an entry whenever something breaks or a test catches a real bug.

| # | What happened | Root cause | Fix | Rule |
|---|---|---|---|---|
| 1 | The borrowed day-trader-skill pack needed changes in every file | Built for the US: New York clock, US holidays, $ and US tickers in each script | Wrote a lean NSE-native desk reusing only its design | Check a borrowed codebase's assumptions before adapting it |
| 2 | TATAMOTORS returned 404 | Tata Motors demerged in 2025 (now TMPV and TMCV) | Watchlist uses TMPV; scans report skipped symbols | Validate every symbol against live data; corporate actions rename tickers |
| 3 | "Infosys" matched "Slone Infosystems" | Substring matching | NSE: exact legal name; headlines: whole-word, case-sensitive acronyms | Never match company names by substring |
| 4 | "Tata Motors CV" counted as TMPV | Bare "Tata Motors" is ambiguous after the demerger | Aliases name PV and CV explicitly | Re-check aliases after corporate actions |
| 5 | Second NSE filing of the day vanished | De-duplicated by title, and NSE titles are just the company name | NSE de-duplicates by link | Pick the duplicate key per source |
| 6 | A plan edited after the risk check still showed READY | Compared a fingerprint stored in the plan instead of recomputing it | Fingerprint recomputed at check and at use | Recompute integrity checks at use time |
| 7 | Printing ₹ crashed the script | Windows console cp1252 | stdout forced to UTF-8 in common.py | Force UTF-8 on Windows |
| 8 | Scripts could not import common under `python -I` | Isolated mode drops the script folder from the path | Run our own scripts without -I | -I is for untrusted code only |
| 9 | Python could not reach Telegram on this PC | Certificate check fails (likely antivirus HTTPS scanning) | Falls back to curl, which uses the Windows store | Keep a transport fallback for TLS-intercepting PCs |
| 10 | Volume filter favoured the busy open and close | Compared each bar with the whole-day average | Same time-of-day average from previous sessions | Compare like with like |
| 11 | A first live test sent about 10 Telegram alerts at once | The "already seen" state was empty, so the day's backlog went out | Pause switch added (`telegram_paused`) | Seed seen-state before the first live run; keep a pause switch |
| 12 | Moneycontrol feeds returned 2024 news | Their RSS stopped updating | Dropped; feeds checked for fresh dates | Check feed freshness, not just that it responds |
| 13 | A test could have sent a real Telegram message | Tests read the real .env | Tests stub load_env; Telegram refuses in offline/test runs | Tests never touch real secrets |
| 14 | A damaged journal crashed the risk check | No validation when reading the CSV | Journal validated; damage raises an error and the trade is blocked | Fail closed on damaged state |
| 15 | "yes buy 100" was accepted for a 14-share plan | The yes-check ignored numbers | A number in the reply must equal the planned quantity | Approvals must match the exact order |
| 16 | INFY exited at 15:25 instead of 15:15 | Yahoo was missing the 15:15 and 15:20 bars that day | A feed gap past flat-by exits at the last price at 15:15 | Exits must not depend on a bar existing |
| 17 | One replay week looked like a result | 5 trades is noise | 20-session replay; judge on larger samples | Never trust a strategy on a week of data |
| 18 | 20-session replay: +₹44.68 net, but charges were ₹47.13, about half the gross profit | Tiny positions (1-9 shares) pay near-fixed costs on every round trip | Results always shown after charges; risk gate requires net reward:risk ≥ 1 | At small size, charges decide the result; always judge net, never gross |
| 19 | Naming the signal agent `signal.py` would have broken subprocess (and the Telegram fallback) | A local file shadows the stdlib `signal` module that subprocess imports | Renamed to `signals.py` | Never name project files after stdlib modules (signal, json, csv, time, random...) |
| 21 | New agents replay: +0.79% vs +0.95% before; 9 of 15 trades ended on the 30-minute time stop, and the 3-loss pause stopped all trading for the last 4 sessions | Time stop too tight for 5-minute ORB moves; the replay never "reviews" so the pause never lifts | Open: test a 60-minute or no time stop; let the replay resume weekly | Tune one rule at a time and replay before keeping it |
| 20 | Fixed targets capped winners while losers ran to the full stop | Exit rule did not follow profit | Break-even at +1R, then a 1R trailing stop | Let profit run with a stop that only moves up |
| 22 | Two cheap Haiku reviewers found 13 real bugs our 58 tests missed (stale PASS after the window, fill above the risk limit, flat-by with a feed gap, "yes sell" on a buy, bar-count time stop, duplicate ideas, no send retry, monitor skipped on a signal error, "debt falls" read as bad news, SBI Cards tagged as SBI, alphabetical seen-list trim, linkless NSE filings merged, re-entries skipping vetoes) | Tests only cover paths we thought of | All fixed with tests; 63 tests | After every build, run a cheap independent review and verify each finding before fixing |
| 23 | 2.5% vs 5% risk on the same 20 sessions (Rs 5,000): 5% made +Rs 256 before charges but paid Rs 397 in charges, ending -2.82%; 2.5% hit the weekly limit, then 3 losses in a row, and the replay never resumed, ending -4.73% after only 6 trades | Charges grow with size, so more risk did not fix a missing edge; the replay has no weekly review so a pause lasts forever | Open: replay should resume the streak pause each Monday like a real review | Raising risk multiplies costs as well as wins; find an edge after charges before sizing up |
| 24 | Four variants on the same 20 sessions (Rs 5,000, 2.5%, Monday resume) all lost after charges: baseline -1.47% (gross +115), 5-min range -3.83%, top-1 in play -4.99%, combo -5.44%. First combo run took 0 trades | US research tweaks did not carry over to these NSE large caps in this window; charges ~Rs 13 a trade; the combo required net 1.5R at a 1.5R planning target, which is impossible | Combo rerun with a 2.5R target; replay resumes streak pauses each Monday | Check a filter can be met before running it; evidence from other markets is a hypothesis, not a result |
| 25 | Two rules from the 96-trade analysis (stop at least 1% away, charges at most 10% of risk) turned the same 20 sessions from -1.47% to +2.02% | Tight stops meant many shares and charges near 0.18R a trade | Kept both rules | Rules found on the same days they are tested on can be overfit; confirm on sessions not used to find them |
| 26 | The 3 X accounts picked for November gave no scorable stock calls: one is news, one posts index options and commodities, one posts chart lessons | Free price data cannot price option premiums, and most "calls" on X are options | People tracker paused; pick accounts that post cash-stock calls with a symbol, or score only stock calls | Check that a data source produces what you can measure before building on it |
| 27 | 60-session replay with the new rules: the 40 older sessions they were never tuned on lost -10.8% (31 trades, 7 wins, gross -211 before charges); the 20 sessions they were found on made +1.21%. Worst drop 14.6%. Predictor trained on 266 ideas did not beat the baseline on 105 unseen ones | The +2.02% was overfitting to the same 20 days; ORB on these 20 large caps shows no edge over Aug-Nov 2026 | Rules kept for now but no edge claimed; predictor stays in shadow | Always judge on sessions not used to build the rules; one good window is not an edge |
| 28 | Weekly momentum (top 2 of 20 large caps, 200-day filters, delivery) over 5 years: Rs 10,000 made +18.4% with Rs 1,740 charges, while holding Nifty made +38.3%; the same rules on Rs 1,00,000 made +45.3% (charges 9.4%), drawdowns 26-31% | The fixed Rs 15.93 DP charge per sale and whole-share rounding weigh far more on small accounts | weekly.py kept as a tool; no tuning done | At small size, fixed per-trade costs can erase a real edge; compare every strategy with simply holding the index |
| 29 | Monthly momentum on a 50-stock list beat Nifty on the untouched 2022-2026 test (Rs 10k +48%, Rs 1L +109% vs Nifty +33%), but dropping 4 stocks that only joined Nifty 50 after 2022 (Trent, BEL, Shriram Fin, Adani Ent) turned it into -6.6% and +27.2% | Survivorship: a stock list chosen today contains the past winners, so the backtest "knows" the future. Also Yahoo range=max silently returns monthly bars | Explicit date ranges for daily data; --exclude to test without later joiners | Use a point-in-time stock list (index members as of each date) or index data; treat a big edge on today's list as suspect until it survives that check |
| 30 | ETF switching 2015-2026 (Rs 10k): holding the Nifty ETF made +240% (10.9%/yr, worst drop 36%); the 200-day trend filter made +162% (8.4%/yr) with less than half the worst drop (17%); dual momentum with gold made +98% (5.9%/yr, drop 29%). First run showed a 90% "drop" | Yahoo prints NIFTYBEES at 13 instead of 129 (and GOLDBEES at 0.34) on 19-20 Dec 2019 | etf.py drops prints more than 40% away from their neighbours | Sanity-check any result that looks impossible against known history before reading it; simple index holding is the bar every strategy must beat |
| 31 | Fable 5.2's 3 combined strategies, rules fixed before seeing data, 2013-2026 at Rs 10k: hold Nifty +369% (drop 36%); 50/50 Nifty/gold +360% (drop 21%); 70/30 momentum tilt +373% (drop 22%); two-key VIX exit +224% (drop 21%); sector pair +429% (drop 39%, Rs 5,955 charges). 9-month check: tilt +340%, sectors +351% | Gold's 2020-26 boom carried the gold mixes (they lagged badly in 2013-19); the sector result moves a lot with the lookback and trades indices that have no cheap ETF | Kept combo.py as a tool | A result that changes a lot with a small parameter tweak is luck; check each half separately, not just the total |
